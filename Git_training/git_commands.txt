# Git Commands Cheat Sheet – Basic to Advanced

| Category | Git Command | Description |
|---|---|---|
| Version | `git --version` | Check Git version |
| Configuration | `git config --global user.name "Siva"` | Configure username |
| Configuration | `git config --global user.email "email@gmail.com"` | Configure email |
| Configuration | `git config --list` | View Git configuration |
| Repository | `git init` | Initialize a Git repository |
| Repository | `git clone <URL>` | Clone remote repository |
| Repository | `git status` | Check repository status |
| Repository | `git remote -v` | Display remote repositories |
| Staging | `git add file.py` | Stage a specific file |
| Staging | `git add .` | Stage all changes |
| Staging | `git restore --staged file.py` | Remove file from staging |
| Commit | `git commit -m "message"` | Commit staged changes |
| Commit | `git commit -am "message"` | Commit changes to tracked files |
| Commit | `git log` | Display commit history |
| Commit | `git log --oneline` | Display compact commit history |
| Commit | `git show <commit-id>` | View commit details |
| Commit | `git diff` | View unstaged changes |
| Commit | `git diff --staged` | View staged changes |
| Branch | `git branch` | List local branches |
| Branch | `git branch <branch-name>` | Create a branch |
git checkout -b feature/test_ravi | checkout the branch |
| Branch | `git switch <branch-name>` | Switch branches |
| Branch | `git switch -c <branch-name>` | Create and switch branch |
| Branch | `git branch -d <branch-name>` | Delete merged branch |
| Branch | `git branch -M main` | Rename current branch to main |
| Merge | `git merge <branch-name>` | Merge another branch |
| Merge | `git merge --abort` | Abort an ongoing merge |
| Remote | `git remote add origin <URL>` | Connect remote repository |
| Remote | `git remote remove origin` | Remove remote connection |
| Push | `git push origin main` | Push main branch to GitHub |
| Push | `git push -u origin main` | Push and set upstream |
| Push | `git push` | Push latest commits |
| Pull | `git pull origin main` | Pull and integrate remote changes |
| Fetch | `git fetch origin` | Download remote changes |
| Fetch | `git branch -r` | List remote branches |
| Clone | `git clone <URL>` | Download an existing repository |
| Undo | `git restore file.py` | Discard unstaged file changes |
| Undo | `git revert <commit-id>` | Create a commit that reverses an earlier commit |
| Undo | `git reset --soft HEAD~1` | Undo last commit, keep changes staged |
| Undo | `git reset --mixed HEAD~1` | Undo last commit, keep changes unstaged |
| Stash | `git stash` | Temporarily save uncommitted changes |
| Stash | `git stash list` | List saved stashes |
| Stash | `git stash pop` | Restore latest stash and remove it |
| Stash | `git stash apply` | Restore stash without removing it |
| Delete | `git rm file.py` | Remove tracked file |
| Rename | `git mv old.py new.py` | Rename tracked file |
| Tags | `git tag` | List tags |
| Tags | `git tag v1.0` | Create a tag |
| Tags | `git push origin v1.0` | Push tag to GitHub |

## Common Git Workflow

```bash
# 1. Initialize repository
git init

# 2. Check status
git status

# 3. Add files
git add .

# 4. Commit changes
git commit -m "Initial commit"

# 5. Create GitHub remote connection
git remote add origin <GITHUB_REPOSITORY_URL>

# 6. Set main branch
git branch -M main

# 7. Push code to GitHub
git push -u origin main

# 8. Pull latest changes
git pull origin main
```

## Developer Feature Branch Workflow

```bash
# Create feature branch
git switch -c feature/customer-data

# Stage changes
git add .

# Commit changes
git commit -m "Added customer data processing"

# Push feature branch
git push -u origin feature/customer-data

# Switch to develop
git switch develop

# Get latest changes
git pull origin develop

# Merge feature branch (if approved and appropriate)
git merge feature/customer-data

# Push develop
git push origin develop
```

Note: In team environments, normally create and approve a GitHub Pull Request instead of directly merging feature branches locally.

## Useful Git Commands for Troubleshooting

```bash
# Check current branch
git branch --show-current

# Check remote URL
git remote -v

# Check commit history
git log --oneline --graph --all

# Check differences
git diff

# Check staged files
git diff --cached

# Check ignored files
git status --ignored

# Check Git configuration
git config --list

# Check upstream tracking
git branch -vv
